ℹ️
HTML Fetch vs. Rendered DOM Extraction

The standard crawler uses high-performance asynchronous HTTP fetch() requests to crawl websites efficiently. However, Single Page Applications (React, Angular, Vue, etc.) that render their content entirely client-side via JavaScript may appear empty in raw HTML responses.

To extract fully rendered JavaScript DOM for a specific web page, open that page in a browser tab and use the active tab extraction tool below.
