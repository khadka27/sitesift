Browser Capabilities & Compliance Notice

Local Processing: All crawling, DOM parsing, and reporting executes 100% locally within your browser. No crawled content is transmitted to external servers.

CORS & Security Boundaries: Manifest V3 extensions with host permissions can fetch public HTTP/HTTPS web pages directly. Sites requiring login credentials, CAPTCHAs, or Cloudflare verification challenges must be accessed through your active browser tab.

JavaScript Rendering: Standard asynchronous fetch requests retrieve static HTML responses. For client-side Single Page Applications (SPAs), utilize the JavaScript Rendering Tool on the crawler dashboard.
